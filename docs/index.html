Automation flows for turning a captured place into game assets

Each flow runs one existing tool with nobody at the controls, checks what it made, and hands a file to the next flow. One tool per flow, so each can be tested on its own and swapped when something better ships.

None of these flows is built yet. This is the list we are specifying, one at a time.

Documented the tool publishes the scripting route we would use To check the route is not confirmed yet

De-lighting

Take the sun and shadows of the capture day out of the colour, so the asset works under any lighting.

Checked for: relight the result and compare it with a photo of the place the flow never saw.
