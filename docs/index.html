Event Logging

This project uses Supabase to log real-world game events. The API endpoint:

POST /rest/v1/events

accepts the following payload:

{
  "test": "string (max 64 chars)",
  "kind": "string (max 64 chars)",
  "session_id": "string (optional)",
  "payload": { /* up to 4KB JSON */ }
}

Getting Started

To start logging events to Supabase:

  1. Use your Supabase publishable key for client-side requests
  2. POST events to the REST API endpoint
  3. Query events using the Supabase client library or REST API
